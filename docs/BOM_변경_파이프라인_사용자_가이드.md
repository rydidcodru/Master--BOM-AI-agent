# BOM 변경 파이프라인 — 사용자 가이드

> **이 문서의 목적**
> 신제품 개발 시 부품 변경 내역을 BOM(부품 목록표)에 반영하는 작업을 AI가 자동으로 도와주는 시스템입니다.
> 개발 담당자가 직접 수백 개의 엑셀 행을 수작업으로 찾아 수정하던 일을 이 시스템이 대신합니다.
> 이 문서는 해당 시스템의 각 화면이 무엇을 의미하고 어떻게 사용하는지 설명합니다.

---

## 전체 흐름 한눈에 보기

```
[1단계] 파일 업로드  →  [2단계] BOM 매핑 확인  →  [3단계] 이력 후보 검토  →  [4단계] BOM 편집
   PPTX + 엑셀 입력        AI가 찾은 부품 확인        과거 사례 참고            최종 BOM 수정
```

담당자가 개발심의회에서 사용하는 **변경점 PPTX 파일** 하나와 **현재 BOM 엑셀 파일** 하나를 업로드하면,
시스템이 AI를 이용해 자동으로 부품을 찾고 변경 이력을 조회하여 BOM에 어떤 수정이 필요한지 제안합니다.

---

## 1단계 — 파일 업로드

![1단계 파일 업로드](../보고서에들어갈\ 사진들/스크린샷\ 2026-06-13\ 오전\ 2.17.33.png)

### 이 화면에서 하는 일
변경점이 정리된 PPTX 파일과 현재 제품의 BOM 엑셀 파일을 시스템에 올립니다.
업로드가 완료되면 AI가 PPTX를 읽어 변경 항목을 추출하고, BOM에서 해당 부품의 위치를 찾습니다.

### 각 항목 설명

| 항목 | 설명 |
|------|------|
| **변경점 PPTX** | 개발심의회 발표 자료. AI가 이 파일을 읽어 "어떤 부품이, 어떻게 바뀌는지"를 자동 추출합니다. |
| **Base BOM (Excel, 선택)** | 현재 양산 중인 제품의 부품 목록 엑셀 파일. 없으면 내장된 기본 파일을 사용합니다. |
| **BOM 매핑 실행** 버튼 | 파일을 올린 뒤 이 버튼을 누르면 AI 분석이 시작됩니다. 수십 초 소요됩니다. |

### 저장된 결과 이어서 진행하기

> **"저장된 BOM 매핑 결과가 있습니다"** 초록 배너가 보이면,
> 이전에 분석했던 결과가 남아 있다는 뜻입니다.
> **"이어서 진행 →"** 버튼을 누르면 다시 분석하지 않고 바로 2단계로 넘어갑니다.
> 분석 시간(수십 초)을 절약할 수 있습니다.

> **테스트 버튼**: "퀵존레인지 Fixture" / "Compact Oven Fixture" — 실제 파일 없이 내장된 샘플 데이터로 전체 흐름을 테스트해볼 수 있습니다.

## 2단계 — BOM 매핑 확인

![2단계 목록](../보고서에들어갈\ 사진들/스크린샷\ 2026-06-13\ 오전\ 2.17.07.png)

### 이 화면에서 하는 일
AI가 PPTX에서 추출한 **변경점 목록**을 보여줍니다.
각 변경점이 BOM의 어느 부품에 해당하는지 AI가 매핑한 결과를 담당자가 눈으로 확인합니다.
내용을 검토한 후 **"이력 검색 실행 →"** 버튼을 눌러 다음 단계로 넘어갑니다.

### 목록의 각 열 설명

| 열 이름 | 설명 |
|---------|------|
| **상태** | 변경 유형 (Changing=변경 / 삭제 / 변경+전체교체) |
| **확정** | 아직은 비어 있습니다. 3·4단계에서 담당자가 확정하는 항목입니다. |
| **레벨** | BOM 구조에서의 깊이. `.1`은 최상위 어셈블리, `..2`는 그 하위, `...3`은 더 아래입니다. |
| **Part No** | BOM에서 AI가 찾아낸 부품 번호 |
| **부품명** | 해당 부품의 이름 |
| **AI 참고 메모** | 이 변경점에 대해 AI가 메모한 내용 (변경 요약, 주의사항 등) |
| **신뢰도** | AI 매핑의 확신 정도. **높음** = PPTX에 부품번호가 명시되어 있어 확실. **중간** = AI가 추론. **낮음** = 불확실. |

### 변경 유형 배지 설명

| 배지 | 색상 | 의미 |
|------|------|------|
| `Changing` | 주황 | 기존 부품의 사양이 바뀌는 경우 |
| `변경` | 파랑 | 부품 번호 자체가 바뀌는 경우 |
| `삭제` | 빨강 | 해당 부품이 BOM에서 제거되는 경우 |
| `전체 교체` | 빨강+진함 | 해당 어셈블리 전체(하위 부품 포함)가 교체되는 경우 |

### 카드 펼치기 — 매핑 상세 보기

![2단계 카드 펼침 - 상세](../보고서에들어갈\ 사진들/스크린샷\ 2026-06-13\ 오전\ 2.17.13.png)

목록에서 항목을 클릭하면 해당 변경점의 상세 정보가 펼쳐집니다.

- **모듈 / 변경내역 / 분야** : PPTX에서 추출한 원문 정보
- **Base P/No** : 현재 BOM에 있는 기존 부품 번호
- **New P/No** : 바뀔 새 부품 번호. PPTX에 명시된 경우 표시되고, 없으면 TBD(미정)
- **BOM 레벨** : 이 부품이 BOM 계층에서 몇 번째 깊이인지
- **매핑 근거** : AI가 이 부품을 어떻게 찾아냈는지 설명

**매핑된 BOM 트리 (상위 5개 / 전체 N개)**
AI가 찾아낸 해당 부품의 위치와 그 하위에 딸린 부품 목록입니다.
레벨이 깊을수록 점(`.`)이 더 많이 붙습니다.

> **예시**: `.1` Plate Assembly,Upper → `..2` Plate Assembly,Upper → `...3` Plate,Top → ...
> 이는 "Plate Assembly,Upper(최상위) 아래에 또 다른 Plate Assembly가 있고, 그 아래 Plate,Top이 있다"는 BOM 구조입니다.

### 전체 교체 vs 부분 변경

![전체 교체 케이스](../보고서에들어갈\ 사진들/스크린샷\ 2026-06-13\ 오전\ 2.11.03.png)

파란 요약 박스에 AI의 판단이 표시됩니다.

> **"전체 교체 판단 — 하위 1866개 행을 삭제하고 이력 케이스 기반으로 새 부품을 채웁니다."**

이는 해당 어셈블리 전체를 교체하는 큰 변경입니다. 하위에 딸린 모든 부품을 새 구성으로 바꿔야 합니다.

반면 **"부분 변경"** 판단이면 특정 부품 하나의 번호만 바뀌는 소규모 변경입니다.

## 3단계 — 이력 후보 검토

![3단계 이력 검토](../보고서에들어갈\ 사진들/스크린샷\ 2026-06-13\ 오전\ 2.10.03.png)

### 이 화면에서 하는 일
AI가 과거 개발심의회 자료에서 **비슷한 변경 사례**를 찾아 보여줍니다.
담당자는 이 이력을 참고해 새 부품 번호를 어떻게 채울지 판단합니다.

### 화면 구성

#### 상단 요약 박스
현재 변경점에 대한 AI의 종합 판단을 한 문장으로 설명합니다.

#### 플로우 화살표 (→ 파이프라인 단계 표시)
```
PPTX 추출  →  BOM 매핑  →  [서브트리 삭제 / Part No 교체]  →  이력 기반 재구성
```
현재 이 변경점이 전체 교체인지 부분 변경인지에 따라 화살표 중간 단계의 표시가 달라집니다.
**주황색 테두리**가 있는 단계가 "이번 변경에서 실제로 수행되는 작업"입니다.

#### 케이스 탭 (케이스 #1 ~ #5)

![케이스 탭 - 직접이력](../보고서에들어갈\ 사진들/스크린샷\ 2026-06-13\ 오전\ 2.10.03.png)

AI가 찾아낸 **과거 유사 변경 사례** 최대 5개가 탭으로 나열됩니다. 가장 관련성 높은 것이 케이스 #1입니다.

| 표시 | 의미 |
|------|------|
| **직접이력** | 이번에 변경되는 것과 **동일한 부품 번호**가 과거에도 변경된 사례. 가장 신뢰도가 높습니다. |
| **유사패턴** | 부품 번호는 다르지만 변경 내용이 비슷한 간접 참고 사례 |
| `LSIL6336F → LSIL6336FE` | 이 케이스가 담긴 과거 심의회 파일명 (구 모델 → 신 모델) |

케이스 표 안에는 그 과거 변경에서 실제로 바뀐 부품들이 나열되어 있습니다.
"이전에 이렇게 변경했으니 이번에도 비슷하게 변경하면 된다"는 참고 자료입니다.

![케이스 탭 - 유사패턴](../보고서에들어갈\ 사진들/스크린샷\ 2026-06-13\ 오전\ 2.11.23.png)

#### 연동부품 제안

> **[변경] Packing Assembly,Gas** — 하위 부품 변경 시 연동 교체 필요
> **[변경] Accessory Assembly,Cavity** — 하위 부품 변경 시 연동 교체 필요

AI가 "이 부품을 바꿀 때 함께 바꾸는 경우가 많다"고 판단한 **추가 변경 후보**입니다.
PPTX에는 없었지만 과거 사례를 보니 같이 변경해야 할 것 같은 부품들입니다.
체크박스를 선택하면 변경점 목록에 추가됩니다.

## 4단계 — BOM 편집

![4단계 BOM 편집 전체](../보고서에들어갈\ 사진들/스크린샷\ 2026-06-13\ 오전\ 1.09.51.png)

### 이 화면에서 하는 일
실제 BOM 전체를 표 형태로 보여주면서, AI가 변경이 필요하다고 판단한 행들을 강조합니다.
담당자가 각 행을 직접 확인하고 **확정** 또는 **제외** 처리합니다.

### 화면 왼쪽 — BOM 전체 표

![4단계 BOM 표 상세](../보고서에들어갈\ 사진들/스크린샷\ 2026-06-13\ 오전\ 2.13.26.png)

전체 BOM이 표로 펼쳐집니다. 색상과 아이콘으로 변경이 필요한 행을 한눈에 알 수 있습니다.

**행 색상 의미**

| 색상 | 의미 |
|------|------|
| 노란 배경 | 변경 대상 행 (기존 부품 번호가 바뀌는 경우) |
| 빨간 배경 | 삭제 대상 행 (이 부품은 BOM에서 제거됨) |
| 초록 배경 | 신규 추가 행 (새로 BOM에 들어오는 부품) |
| 흰 배경 | 변경 없는 기존 행 |

**상태 열 배지**

| 배지 | 의미 |
|------|------|
| `변경` | 이 부품의 번호나 사양이 바뀜 |
| `삭제` | 이 부품이 BOM에서 제거됨 |
| `추가` | 이 부품이 새로 BOM에 추가됨 |
| `스 미확정` | AI가 변경이 필요하다고 봤지만, 아직 담당자가 확인하지 않은 상태 |
| `스 확정` | 담당자가 확인 완료한 상태 |

**상단 카운터 (변경 N / 추가 N / 삭제 N / 미확정 N)**
변경 유형별 행 수를 요약해서 보여줍니다. **미확정이 0이 되어야 최종 저장이 가능**합니다.

**이전 변경 / 다음 변경 버튼**
변경 대상 행들 사이를 순서대로 이동하면서 검토할 수 있습니다. 표를 직접 스크롤하지 않아도 됩니다.

### 화면 오른쪽 — 변경 상세 패널 (서랍)

행을 클릭하면 오른쪽에 상세 패널이 열립니다.

![4단계 우측 패널 - 메모](../보고서에들어갈\ 사진들/스크린샷\ 2026-06-13\ 오전\ 2.15.10.png)

**패널 상단 — 부품 정보**
- 선택된 행의 부품명과 번호
- PPTX에서 추출된 변경 내역 요약
- AI가 이 변경에 대해 판단한 내용

**NEW P/NO 입력 칸**
새 부품 번호를 담당자가 직접 입력하는 칸입니다.
3단계에서 이력을 참고해 확정된 번호를 여기에 입력합니다.

**확정 버튼**
입력을 완료하면 확정 버튼을 누릅니다. 해당 행이 "미확정"에서 "확정"으로 바뀝니다.

---

![4단계 우측 패널 - 이력 케이스](../보고서에들어갈\ 사진들/스크린샷\ 2026-06-13\ 오전\ 2.16.56.png)

패널 하단에는 3단계에서 봤던 **이력 케이스 요약**이 다시 표시됩니다.
BOM을 수정하면서 바로 옆에서 과거 사례를 참고할 수 있도록 한 것입니다.

## 부록 — 용어 정리

| 용어 | 풀어쓰기 |
|------|---------|
| **BOM** | Bill of Materials. 제품을 구성하는 모든 부품의 목록표. 어떤 부품이 몇 개 들어가는지 계층 구조로 정리된 엑셀 파일. |
| **PPTX** | 개발심의회 발표용 파워포인트 파일. 이 안에 "어떤 부품을 어떻게 바꿀 것인가"가 표 형태로 정리되어 있습니다. |
| **Base BOM** | 현재 양산 중인 제품의 BOM. 이것을 기준으로 변경사항이 반영됩니다. |
| **Part No (P/No)** | 부품 번호. LG전자 내부에서 각 부품에 부여된 고유 식별 번호 (예: AGU74969449). |
| **Base P/No** | 변경 전 기존 부품 번호 |
| **New P/No** | 변경 후 새 부품 번호. 아직 미정이면 TBD로 표시됩니다. |
| **레벨 (.1 / ..2 / ...3)** | BOM의 계층 깊이. 점이 많을수록 더 세부 부품입니다. `.1`은 최상위 어셈블리, `....4`는 4단계 하위 부품. |
| **어셈블리** | 여러 부품을 조립한 묶음 부품. 예: "Plate Assembly,Upper"는 여러 판금 부품들의 조립체. |
| **전체 교체** | 해당 어셈블리와 그 하위의 모든 부품을 새 구성으로 통째로 바꾸는 것 |
| **직접이력** | 동일 부품 번호로 과거에 변경이 있었던 기록. 가장 신뢰할 수 있는 참고 자료. |
| **연동부품** | 주요 변경 부품을 바꿀 때 함께 바꿔야 하는 관련 부품. AI가 과거 사례를 보고 추천합니다. |
| **신뢰도** | AI 매핑 결과의 확신 정도. 높음/중간/낮음 3단계. |
| **미확정** | AI가 변경 필요하다고 표시했지만 담당자가 아직 검토하지 않은 항목 |

---

*본 시스템은 AI를 활용한 자동화 도구이며, 최종 변경 내역의 정확성은 담당자가 직접 검토·확정해야 합니다.*
